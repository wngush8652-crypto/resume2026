# 🧑‍💻 나를 소개하는 웹 이력서 프로젝트 (My Introduction Project)
> 이스트소프트(ESTsoft) 오르미 프론트엔드 개발자 과정 개인 프로젝트

## 📌 1. 기획 의도 및 프로젝트 소개
- 비전공자 특유의 끈기와 끊임없는 배움에 대한 열정을 담아 나만의 스토리와 역량을 전달하는 웹 이력서입니다.
- 코드 한 줄로 화면이 바뀌고 사용자에게 새로운 가치를 제공하는 프론트엔드의 매력을 극대화하여 설계했습니다.
- 인사담당자에게 신뢰감을 줄 수 있도록 가독성을 최우선으로 고려한 레이아웃을 구현했습니다.

## 🛠️ 2. 사용 기술 스택 (Tech Stack)
- **Frontend:** HTML5, CSS3
- **Design:** Figma (PC용 2단 레이아웃 및 모바일 반응형 1단 레이아웃 교차 설계)

## 📱 3. 주요 기능 및 특징
- **반응형 웹 디자인:** 데스크톱(MacBook 14") 화면의 시원한 2단 구성과 모바일(iPhone) 화면의 정석적인 1단 스크롤 레이아웃 완벽 지원
- **시각적 역량 표현:** 내 프로그램 능력을 한눈에 볼 수 있는 깔끔한 게이지 바(Bar) 형태의 그래프 구현
- **체계적인 이력 관리:** 학력사항, 교육 경력, 자격증 및 프로젝트 히스토리를 직관적인 UI로 정렬
